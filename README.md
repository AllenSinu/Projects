# Rock Paper Scissors

A real-time Rock Paper Scissors game using hand gesture recognition.

## Features
- Real-time hand detection
- Rock/Paper/Scissors recognition
- Best of 3/5
- Live score
- Countdown timer

## Technologies
- Python
- OpenCV
- MediaPipe
